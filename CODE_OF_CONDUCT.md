# Code of Conduct

## Our standard

Participants in this project — issues, pull requests, discussions — are
expected to be respectful and constructive. Disagreement about technical
approach is welcome; personal attacks, harassment, or discriminatory
language are not.

## Scope

This applies to all project spaces: the repository, issues, pull requests,
and any associated discussion channels.

## Enforcement

Violations may be reported by opening a GitHub issue tagged
`conduct`, or contacting the maintainer directly. Maintainers may remove
comments, close issues/PRs, or block participants who violate this
standard.

Adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
